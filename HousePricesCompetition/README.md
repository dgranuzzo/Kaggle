# House Prices ML Pipelines

This repository contains three scikit-learn pipelines for the Kaggle **House Prices: Advanced Regression Techniques** competition. Each script uses the provided `train.csv` and `test.csv` files in the root directory and saves predictions or diagnostics back to the same folder.

## Requirements

- Python 3.11 or later.
- Install dependencies:
  ```bash
  python -m pip install -r requirements.txt
  ```
  If you do not have a `requirements.txt`, install the core packages manually:
  ```bash
  python -m pip install pandas scikit-learn matplotlib numpy
  ```

## Project Structure

- `houseprice.py` - Baseline Random Forest pipeline that outputs `rf_predictions.csv`.
- `housepriceboosted.py` - Gradient-boosted tree pipeline (`HistGradientBoostingRegressor`) that outputs `hgb_predictions.csv`.
- `houseprice_compare.py` - Comparison tool that evaluates both pipelines with cross-validation, prints metrics, and generates comparison plots.
- `train.csv`, `test.csv` - Kaggle competition data (already included).
- `model_rmse_comparison.png`, `predictions_vs_actual.png` - Plots generated by the comparison script.

## Usage

Run the commands below from the repository root (`D:\projetos\Kaggle\HousePricesCompetition`).

### 1. Random Forest baseline

```bash
python houseprice.py
```
Outputs:
- Cross-validated RMSE summary in the terminal.
- `rf_predictions.csv` containing predicted `SalePrice` values for submission.

### 2. HistGradientBoosting pipeline

```bash
python housepriceboosted.py
```
Outputs:
- Cross-validated RMSE summary in the terminal.
- `hgb_predictions.csv` containing boosted-tree predictions.

### 3. Model comparison and visualization

```bash
python houseprice_compare.py
```
Outputs:
- RMSE metrics for both models and the winner (lower is better).
- `model_rmse_comparison.png` - RMSE bar chart with error bars.
- `predictions_vs_actual.png` - Scatter plot of cross-validated predictions vs ground truth for each model.

> **Tip:** The comparison script performs repeated preprocessing and cross-validation, so it can take a few minutes to finish.
